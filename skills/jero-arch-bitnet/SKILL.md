# `jero-arch-bitnet` Architecture Recipe Invariants

- Implement `jero_core::ArchRecipe` for BitNet architectures (`bitnet`, `bitnet-b1.58`, and `bitnet-25`), hydrating hyperparameters via `BitNetRecipe::from_gguf(&GgufFile<'_>)` and validating weights via `validate_model`.
- Enforce canonical BitNet norm and `SubLN` placement cleanly without fallback loops: `blk.{l}.attn_norm.weight` (`[hidden_dim]`) before Q/K/V, `blk.{l}.attn_sub_norm.weight` (`[total_q]`) before `attn_output`, `blk.{l}.ffn_norm.weight` (`[hidden_dim]`) before gate/up, and `blk.{l}.ffn_sub_norm.weight` (`[ffn_dim]`) before `ffn_down`.
- Repack `TQ1_0`, `TQ2_0`, `I2_S`, and `Q8_0` projection weights once at load time inside `BitNetModelCache` into `128-byte`-aligned `8x16` `i8` tiles alongside cached `f32` `SubLN`/output norms, preserving bit-exact `i32` ternary dot accumulation parity without per-step block re-unpacking.
- Keep steady-state `decode_step` and `decode_step_with_cache` strictly zero-heap-allocation when a caller attaches `ScratchWorkspace::new(recipe.decode_scratch_bytes(max_seq))` via `ExecutionContext::with_scratch`: partition `128-byte`-aligned `ScratchScope` slices before the layer loop, format layer keys on the stack (`StackLayerKey`), deduplicate Pre-QKV (`3x -> 1x`) and Pre-FFN (`2x -> 1x`) `SubLN` (`quantize_absmax_i8_rvv`), precompute token `RoPE` `cos`/`sin` tables once (`apply_rope_heads_with_cos_sin`), and pass scratch scores to `gqa_causal_attention_with_scratch_f32` for arbitrary `seq_len > 2048`.
- Partition `M = 1` cached ternary `BitLinear` and compact `128,256`-row LM-head projections deterministically across `DecodeWorkerPool` (`BitNetModelCache::{with_decode_workers, set_decode_workers, decode_workers}`, clamped `1..=8` default outside Miri and `1` on Miri or deferred caches) using `TILE_N = 8` multi-row RVV 1.0 `compute_tile_row0_dots_rvv` and zero-alloc `QuantizedActQ8View::quantize_row_in_scope` + `RepackedWeight::gemv_view_rows` (`CompactLmHeadMatrix::project_logits_with_pool_and_scope`), producing bit-identical `f32` logits across worker counts.
- Execute multi-token `prefill_step` prompts through batched `[M, K]` projections (`RepackedTernaryMatrix::bitlinear_gemm` / `gemm_i8_ime` and streaming/RVV/scalar fallbacks) using shared `BatchedSubLnActivations` (`1x` Pre-QKV `SubLN` across Q/K/V, `1x` Pre-FFN `SubLN` across gate/up), batched `NeoX` `RoPE`, causal GQA via `gqa_causal_attention_prefill_f32` with chunked KV continuity, and single final-token `M - 1` `output_norm` + `project_lm_head` evaluation (`PrefillSubLnStats`).
- Keep tied/untied `128,256 x 2560` `F16`/`BF16`/`Q8_0` `token_embd.weight` / `output.weight` tables in compact `128-byte`-aligned storage (`dense_f32_max_elems = 0`, zero full-table `f32` expansion), cache absence of untied `"output.weight"` against `(anchor, tensor_count, total_weight_bytes)` so tied models never trigger default `ModelWeights::contains_tensor` error-string allocations, and validate `BitNetVocabContract` bounds including Llama-3 `<|eot_id|>` (`128009`) and `<|end_of_text|>` stops.
- Execute full `0..=position` causal GQA via `ExecutionContext::kv_view_mut` (`KvCacheView`) when `KvGeometry` is attached, respecting optional `sliding_window`, `compute_logits`, and chunk `start_position`.
- Apply `output_norm.weight` once (no duplicate `SubLN`), fall back to tied `token_embd.weight` when `output.weight` is absent, and keep zero heap allocations inside the decode transformer layer loop.
- Use `usize` for tensor slice indexing and memory offsets, and `u32` for architectural hyperparameters and token identifiers.
